## MicroPython テストスクリプトをX68kで実行する

micropython-x68k/tests 以下にあるMicroPython Test SuiteをX68kで実行するためのスクリプトです。

### 実行手順

micropython-x68k/ 以下のファイルがクロス環境 - X68k間で共有されていることを前提とします

#### MicroPythonのビルド

* クロス環境で ports/x68k 以下でmakeを行い、micorpyhton.x をビルドする
* build/micropython.x が生成されることを確認します

#### テストスクリプトの実行

* X68k上で ports/x68k/test/pytest に移動し、 runall.bat を実行する
  * テストスクリプトを実行して結果を log-* ディレクトリに保存します

#### テスト結果の確認

* クロス環境で check.sh を実行する
  * 実行結果を期待値と比較して結果を表示します
  * 期待値は、tests/ 内に *.exp ファイルが存在するものについてはそのファイルを、存在しないものについてはクロス環境上で CPython(python3) で同じスクリプトを実行し、その結果を使用して比較します
  * 各テストについて、比較結果が以下のいずれかで表示されます
    * [ OK ] 期待値と一致
    * [ NG ] 期待値と不一致
    * [SKIP] X68k版に機能が存在しないためスキップ
    * [IGNORE] X68k版で結果が一致しないことが分かっているテスト
  * [ NG ] が一つも出なければ正常です
* check.sh スクリプトは以下のオプションをサポートしています
  * `-n` : 結果が [ NG ] のテストのみを表示します
  * `-d` : 結果が [ NG ] となったテストについて、期待値と実行結果の差分を表示します
  * <テスト名> : 特定のテストグループのみを比較します

### checkskip.txt ファイルについて

checkskip.txt ファイルは、X68k版で期待値と異なる結果になることが分かっているテストを記述したファイルです。このファイルに記述されたテストは、結果の確認時に [IGNORE] としてスキップされます。

主に以下のような要因で差分が発生します。

* 68000 CPUの仕様に起因するもの (エンディアン、アライメントの差異)
* X68kで対応していない機能 (async等)
* シフトJIS対応
* 改行コードの違い (CR+LF と LF)
